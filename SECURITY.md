# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in `@vivsh1999/upupload`, please report it by opening an issue on the [GitHub repository](https://github.com/vivsh1999/upupload/issues).

Do not disclose the vulnerability publicly until it has been addressed by the maintainers.

We will acknowledge receipt of your report within 48 hours and provide a timeline for a fix.
