Custom Pipeline

Three plugins composed together: createRawToJpegPlugin() handles RAW/HEIC/TIFF, createJpegCompressorPlugin() handles JPEG/PNG/WebP, and a custom metadata-annotator reads image dimensions. Each plugin only runs when supports() matches. Pipeline options customised — 80% quality, 2560px max, 320px thumbnails.
